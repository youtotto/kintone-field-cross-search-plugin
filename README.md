# 一覧サポート for kintone（旧: 横断検索プラグイン）

kintone の一覧画面で「探す・絞り込む・数える・目立たせる」を、その場でできるようにする無料のプラグインです。

横断検索プラグイン（v1.0.1）の後継です。**同じプラグイン ID** なので、横断検索プラグインを使っている環境では、読み込むと「更新」になり、これまでの検索の設定はそのまま引き継がれます。更新の前に [アップデート手順](docs/アップデート手順_2.0.4.md) をお読みください。

## ダウンロードと導入

[Releases](https://github.com/youtotto/list-support/releases/latest) から次のファイルをダウンロードします。

| ファイル | 用途 |
|---|---|
| `field-cross-search-2.0.4-free-bundle.zip` | 説明書付きの配布用 ZIP（おすすめ）。**ZIP を解凍し、中の `field-cross-search-2.0.4-free-plugin.zip` を kintone へ読み込みます。bundle 自体は kintone に直接読み込みません** |
| `field-cross-search-2.0.4-free-plugin.zip` | kintone に直接読み込むプラグイン（bundle の中身と同じファイル） |
| `SHA256SUMS.txt` | 上記 ZIP の SHA-256 |

1. kintone システム管理 →「プラグイン」→「読み込む」で `field-cross-search-2.0.4-free-plugin.zip` を ZIP のまま選びます。
2. 使うアプリの「アプリの設定」→「プラグイン」でプラグインを追加し、設定画面で使う機能を設定して保存します。
3. 「アプリを更新」を押すと、一覧画面に反映されます。

横断検索プラグイン（v1.0.1）から更新する場合は、[アップデート手順](docs/アップデート手順_2.0.4.md) をご覧ください。変更点と動作確認の状況は [リリースノート](docs/RELEASE_NOTES_v2.0.4.md) にまとめています。

## できること

一覧画面の上に、次の機能を必要な分だけ出せます。どれも設定画面で機能ごとにオン・オフできます。

| 機能 | 内容 |
|---|---|
| 🔍 横断検索 | 複数のフィールドをまとめてキーワード検索します（横断検索プラグインの機能）。 |
| 🎚 クイックフィルター | よく使うフィールドの絞り込み欄を並べます。文字列は部分一致、選択肢は選んだ値、数値・日付は範囲、ユーザー選択は「自分」で絞り込みます。 |
| 🔘 クイックボタン | よく使う条件（例: 回答期限が今日まで）をボタンにします。押すと絞り込み、もう一度押すと解除します。 |
| 🧮 集計 | 表示中の一覧の条件に一致する全レコードの件数と、数値の合計・平均を表示します。 |
| 🎨 条件付き装飾 | 条件に一致するレコードの行やセルに色を付けます（表形式の一覧）。 |

横断検索・クイックフィルター・クイックボタンの条件は、kintone 標準の絞り込み（漏斗アイコン）や一覧自体の条件に **AND で足して** 絞り込みます。条件をすべて解除すると、標準の絞り込みだけの一覧に戻ります。

### 🔍 横断検索

- テキスト: 文字列（1行 / 複数行）・リッチエディター・リンク（部分一致）
- 選択肢: ドロップダウン / ラジオボタン / チェックボックス / 複数選択（選択肢の完全一致）
- 添付ファイル（部分一致）
- 複数の語はスペースで区切ります。AND（すべての語を含む）/ OR（いずれかの語を含む）は一覧画面で利用者が切り替えられます。設定画面では、一覧を開いたときの初期値を指定します。
- 設定時のフィールド構成を保存しておき、その後フィールドが変更・削除された場合は、該当するフィールドを検索対象から外して警告を表示します（検索自体は続けられます）。

### 🎚 クイックフィルター・🔘 クイックボタン

- クイックフィルターは、入力して「絞り込む」（または Enter）で一覧を絞り込みます。「解除」で外れます。
- クイックボタンは、1 つのボタンに条件を 3 つまで設定できます（すべてを満たすレコードに絞り込み）。日付の条件には、今日から何日後（前はマイナス）、特定の日付、今週・先週・来週・今月・先月・来月・今年のような期間を使えます。同時に押せるボタンは 1 つです。
- 条件のフィールドが削除・変更されたボタンは、押せなくなります（途中までの条件で絞り込むことはしません）。

### 🧮 集計

- 件数は常に表示します。合計・平均は、数値フィールドと、表示形式が数値の計算フィールドで使えます。
- 表示中のページだけでなく、一覧の条件に一致する全レコードを集計します。一致するレコードが 1 万件を超える場合は、件数だけを表示します。
- 平均は空欄のレコードを除いて計算し、除いた件数を表示します。

### 🎨 条件付き装飾

- ルールごとに、条件（フィールド・比べ方・値）、色を付ける場所（行 / セル）、色（赤・黄・青・緑・グレー・赤字太字・太字のみ）を選びます。
- 行のルールは上にあるものが優先されます。セルのルールは行の色より優先されます。

## 設定方法

1. アプリの「アプリの設定」→「プラグイン」で、一覧サポート for kintone の設定（歯車）を開きます。
2. 使う機能のスイッチをオンにして、内容を設定します。

   | 機能 | 設定すること | 無料版で設定できる数 |
   |---|---|---|
   | 横断検索 | 検索対象のフィールド、AND / OR の初期値、一度に検索できる語の数（1〜10、既定 5） | ― |
   | クイックフィルター | 絞り込み欄に出すフィールド | 5 つまで |
   | クイックボタン | ボタンの名前と条件（フィールド・比べ方・値） | 5 個まで（1 個に条件 3 つまで） |
   | 集計 | 集計するフィールドと、合計か平均か | 2 つまで |
   | 条件付き装飾 | 条件・色を付ける場所・色 | 3 ルールまで |

3. 「保存」を押し、アプリの設定画面で「アプリを更新」を押します。

横断検索プラグインから更新したアプリでは、設定画面に「アプリ内横断検索プラグインの設定を引き継ぎました。」と表示されます。保存しなくても横断検索はこれまでどおり使えます。新しい機能を使うときだけ、上の手順で設定して保存してください。

## 検索条件の扱い

- 検索語やクイックフィルターの値、押したボタンは URL に保持されるため、ページ送りや並べ替えの後も維持されます。
- プラグインの条件を付けたまま、標準の絞り込みの条件を変えたり、別の一覧に切り替えたりすると、プラグインの条件は外れ、新しい条件だけの一覧になります。
- 一覧の条件に、削除されたユーザー・組織・グループ・選択肢・ステータスなどが含まれていて、一覧の絞り込み条件を取得できない場合は、条件を足す操作と集計を中止し、「一覧の絞り込み条件を取得できませんでした。画面を再読み込みしてから、もう一度お試しください。解消しない場合は、標準の絞り込み条件を確認するか、アプリ管理者にお問い合わせください。」と表示します（条件が欠けたまま絞り込んだり、集計したりしないため）。

## 注意事項・制限

- **更新は環境全体に反映されます。** プラグインの読み込み（更新）は、そのプラグインを使っているすべてのアプリに反映されます。アプリごとに版を選ぶことはできません。
- PC 版の一覧画面だけで動作します（モバイル版、詳細画面・編集画面では動作しません）。
- 集計・条件付き装飾は表形式の一覧で使えます（カレンダー形式の一覧では表示しません）。
- クイックフィルター・クイックボタン・集計・条件付き装飾は、テーブル（サブテーブル）の外のフィールドが対象です。
- ドロップダウンなどの選択肢の検索は、選択肢と完全に一致した語だけが対象です。
- 数値・日付・ユーザー選択・組織選択・グループ選択は、横断検索の対象外です。数値・日付・ユーザー選択は、クイックフィルター・クイックボタンで絞り込めます（組織選択・グループ選択はどの機能でも対象外です）。
- 日時の範囲（クイックフィルター）と日時の装飾は、利用者の端末の日付で区切ります。
- 標準の絞り込みを保つ仕組みは、kintone の一覧画面の URL の扱い（公開されている仕様ではない部分を含む）に合わせています。kintone の更新で変わる可能性があります。

## 仕組み（簡易）

1. プラグインの設定画面で機能と条件を設定します。横断検索の対象フィールドは、設定時のフィールド定義もあわせて保存します。
2. 一覧画面を開くと、現在のフィールド定義と比べ、使えるフィールドだけで検索・絞り込みの欄を作ります。
3. 検索・絞り込みを実行すると、kintone が一覧に適用している条件（一覧自体の条件と標準の絞り込み）を JavaScript API で取得し、プラグインの条件を AND で足して一覧を開き直します。
4. 集計は、一覧に適用されている条件で REST API からレコードを 500 件ずつ取得して計算します。装飾は kintone の公式 API（一覧のレコードのスタイル設定）で付けます。

## 開発方針

- 設定時の意図を尊重し、実行時に壊れないことを優先します。
- 条件を確実に取得できないときは、推測で絞り込まずに操作を止めて案内します。
- 実運用で起こりうるフィールドの変更を前提に設計しています。
