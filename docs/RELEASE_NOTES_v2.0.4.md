# 一覧サポート for kintone 2.0.4（無料版）

2026-10-14

## 修正内容

一覧画面でレコードを個別削除しても、プラグインの件数・合計・平均に削除前の値が残る不具合を修正しました。削除が成功すると現在の絞り込み条件で再集計し、ページを再読み込みしなくても結果を更新します。

削除を取り消したときや削除が失敗したときは再集計しません。削除前に始まった通信の結果で、新しい集計が上書きされることも防ぎます。設定形式・無料版の機能上限・プラグインIDは変更ありません。2026-10-05に公開した統一アイコンを継続使用します。

- 自動テスト226件が成功（今回の回帰テスト8件を含む）。削除成功・取消、古い通信の成功／失敗、集計欄がない場合、再取得失敗、条件取得不能、集計無効などを確認しました。

## 制約

kintone標準のページ送り横にある件数表示は、個別削除後も再読み込みまで古い値が残る場合があります。今回更新するのは、プラグインが表示する集計欄です。その他の対応範囲・制約は[製品説明](../README.md)を参照してください。
