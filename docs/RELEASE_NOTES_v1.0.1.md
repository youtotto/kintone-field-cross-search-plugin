# Field Cross Search v1.0.1

設定の変更や再設定は不要です。プラグインを更新するだけで適用され、これまでの設定はそのまま引き継がれます。

## 改善

- **AND / OR を一覧画面で切り替えられるようになりました。** 検索バーの「AND | OR」で、利用者がその場で条件を選べます（AND：すべての語を含む／OR：いずれかの語を含む）。プラグイン設定の AND / OR は、一覧画面を開いたときの初期値として使われます。
- 選んだ AND / OR は URL に保持され、ページ送りや並べ替え、再読み込みの後も維持されます。検索を解除しても選択はそのまま残ります。
- 検索中の条件を一覧画面に表示するようにしました（例：「検索中: 東京 営業 / AND（すべて含む）」）。「クリア」は検索中だけ表示されます。
- 検索結果が 0 件のとき、一致するレコードがない旨を表示するようにしました。
- 検索語が上限（既定 5 語、設定で 1〜10）を超えた場合に、対象外になった語を通知するようにしました。入力した内容はそのまま残ります。
- ラジオボタン・チェックボックス・複数選択を検索対象にできるようになりました（ドロップダウンと同じく、選択肢と完全に一致した語で検索します）。
- リッチエディターを検索対象にできるようになりました（部分一致）。
- 設定後にフィールドが変更・削除された場合の表示を見直しました。検索対象フィールドの一覧で、使用中のものと除外中のものを見分けられます。
- キーボード操作とフォーカス表示を改善しました。
- 設定画面の不要なコードを整理しました。設定画面では、保存済みの検索対象がフォームから無くなっている場合に注意書きを表示します。

## 修正

- 一覧画面が再表示されたあとに、検索・クリアなどが操作できなくなることがある問題を修正しました。
- 日本語入力の変換を確定する Enter で、意図せず検索が実行される可能性がある問題を修正しました。
- 検索語の上限の初期値が画面によって食い違っていた問題を修正しました（5 語に統一。保存済みの設定値はそのまま使われます）。
- どのフィールドでも検索条件にできない語（選択肢に一致しない語など）が、何も表示されずに無視される問題を改善しました。該当する語を画面上でお知らせします。
- 検索対象フィールドの件数表示と一覧の内容が一致しないことがある問題を修正しました。

## その他

- 動作を検証する回帰テストを追加しました。

## 注意

- 数値・日付・ユーザー選択・組織選択・グループ選択は、引き続き検索対象外です（kintone 標準の絞り込みをご利用ください）。
- リッチエディターや文字列の部分一致検索の結果は、kintone 標準の絞り込み（次のキーワードを含む）と同じです。登録・更新した直後のレコードは、検索に反映されるまで少し時間がかかることがあります。
