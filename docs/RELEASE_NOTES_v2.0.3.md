# 一覧サポート for kintone 2.0.3（旧: 横断検索プラグイン）

横断検索プラグイン v1.0.1 の次の公開版です。名前を「一覧サポート for kintone」に変え、一覧画面で使える機能を追加しました。2.0.0〜2.0.2 は公開前の検証用の版で、公開していません。

## 更新の前にお読みください

- **プラグイン ID は横断検索プラグインと同じです。** 読み込むと「更新」になり、この環境で横断検索プラグインを使っているすべてのアプリに反映されます。アプリごとに版を選ぶことはできません。
- **検索の設定は引き継がれます。** 検索対象のフィールド、AND / OR の初期値、語の数の上限はそのまま使われ、再設定は不要です。
- 新しい機能は、設定するまで一覧画面に表示されません。更新しただけでは、一覧画面の見た目は横断検索プラグインと同じです。
- 更新の手順と元に戻す方法は `docs/アップデート手順_2.0.3.md` をご覧ください。

## 新しい機能

- **クイックフィルター**: よく使うフィールドの絞り込み欄を一覧の上に並べます（無料版は 5 つまで）。文字列は部分一致、選択肢は選んだ値、数値・日付は範囲、ユーザー選択は「自分」で絞り込みます。
- **クイックボタン**: よく使う条件をボタンにします（無料版は 5 個まで、1 個に条件 3 つまで）。押すと絞り込み、もう一度押すと解除します。
- **集計**: 表示中の一覧の条件に一致する全レコードの件数と、数値の合計・平均を表示します（無料版は 2 つまで。1 万件を超える場合は件数だけ）。
- **条件付き装飾**: 条件に一致するレコードの行やセルに色を付けます（無料版は 3 ルールまで。表形式の一覧）。

## 横断検索の変更点

- kintone 標準の絞り込み（漏斗アイコン）や一覧自体の条件を残したまま、検索語で絞り込むようにしました。v1.0.1 では、検索すると標準の絞り込みの条件が外れていました。
- 横断検索・クイックフィルター・クイックボタンの条件は、まとめて 1 つの条件（AND）として一覧に適用します。どれかを解除しても、ほかの条件と標準の絞り込みは残ります。
- 一覧の条件に削除されたユーザー・組織・グループ・選択肢・ステータスなどが含まれていて、一覧の絞り込み条件を取得できない場合は、条件を足す操作と集計を中止し、次の案内を出すようにしました。条件が欠けたまま絞り込んだり、絞り込みの無い範囲を集計したりしないためです。
  - 操作した欄: 「一覧の絞り込み条件を取得できませんでした。画面を再読み込みしてから、もう一度お試しください。解消しない場合は、標準の絞り込み条件を確認するか、アプリ管理者にお問い合わせください。」
  - 集計欄: 「現在の絞り込み条件を読み取れないため、集計できません。」に続けて同じ対処方法

## 設定画面

- 機能ごとにオン・オフと設定をまとめた画面になりました。
- 横断検索プラグインの設定のままのアプリで開くと、「アプリ内横断検索プラグインの設定を引き継ぎました。」と表示します。保存しなくても横断検索は使えます。
- 保存すると、新しい機能の設定を追加で保存します。横断検索プラグインと同じ形の検索の設定も残します（v1.0.1 に戻したときの動作は、開発側では確認していません）。

## 動作確認の状況（2026-09-30 時点）

開発側で次の範囲を確認しました。すべての機能・組み合わせ・環境を確認したわけではありません。

### 自動テスト

- 218 件のテストがすべて通っています（jsdom 上で kintone の API を模したもの）。

### 実機で確認した範囲（2.0.3、Chrome、検証用のアプリ）

- 表形式の一覧を開いたときの件数・合計・平均の表示
- 標準の絞り込みを付けた一覧での横断検索（標準の条件が残り、件数・合計が一致する）
- 標準の絞り込み＋横断検索＋クイックフィルター＋クイックボタンの組み合わせと、ボタン → クイックフィルター → 検索の順の解除（標準の絞り込みだけの一覧に戻る）
- 絞り込みの無い一覧での横断検索
- 一覧の絞り込み条件を取得できない一覧（削除した選択肢を標準の絞り込みに含む一覧）で、横断検索・クイックフィルター・クイックボタンの操作が中止され、URL が変わらず、上の案内が表示されること。集計欄も数値を出さずに案内を表示すること
- 一部だけ確認: 標準の絞り込みを変えたときの集計（一覧の切り替え後の集計は確認していません）、クイックフィルターは優先度の絞り込みだけ

### 前の検証版（2.0.2）で実機確認し、2.0.3 では確認し直していないもの

2.0.3 で変えたのは、上の案内の文面だけです。

- 5 種類のクイックフィルターの絞り込みと、それぞれの解除
- 条件付き装飾（行の色・セルの赤字太字、ページを送った後の表示）
- 標準の絞り込みの変更や一覧の切り替えで、プラグインの条件が外れること
- 一覧自体に絞り込み条件がある一覧での横断検索

### 擬似検証

- **旧版の設定の引き継ぎ**: 2.0.3 を入れた環境で、アプリのプラグイン設定を横断検索プラグイン v1.0.1 と同じ形（検索の設定 4 項目だけ）に置き換えて確認しました（PASS）。引き継ぎの案内が表示され、検索対象・AND / OR・語の数の上限が同じで、新しい機能は無効のまま、横断検索がこれまでどおり動くこと、元の設定に戻せることを確かめています。プラグインの更新（ZIP の読み込み）そのものは、この方法では確かめられません。

### 未実施

- v1.0.1 が入った環境で 2.0.3 の ZIP を読み込む、実際の更新（開発側に別の検証環境がないため）
- 標準の絞り込みを付けた状態での、ページ送り・並べ替え
- プラグインが一覧を開き直して「標準の絞り込み（または一覧）が変わったため、一覧サポートの条件を解除して表示し直しました。」と案内する動作（確認した操作では、kintone 側で条件が外れるため、この案内は出ませんでした）
- Chrome 以外のブラウザー、1 万件を超える一覧、カレンダー形式の一覧
- v1.0.1 に戻したときの動作

## 注意

- PC 版の一覧画面だけで動作します（モバイル版では動作しません）。
- 組織選択・グループ選択は、どの機能でも対象外です。数値・日付・ユーザー選択は横断検索の対象外ですが、クイックフィルター・クイックボタンで絞り込めます。
- 標準の絞り込みを保つ仕組みは、kintone の一覧画面の URL の扱い（公開されている仕様ではない部分を含む）に合わせています。kintone の更新で変わる可能性があります。
