# 横断検索プラグイン（v1.0.1）から一覧サポート for kintone 2.0.3 への更新手順

横断検索プラグインをお使いの方が、一覧サポート for kintone 2.0.3 に更新するときの手順です。

## 更新の前に

- **同じプラグインの更新です。** 一覧サポート for kintone は、横断検索プラグインと同じプラグイン ID を使っています。2.0.3 の ZIP を読み込むと、新しいプラグインとして追加されるのではなく、横断検索プラグインが 2.0.3 に更新されます。
- **環境全体に反映されます。** 更新は、この kintone 環境で横断検索プラグインを使っているすべてのアプリに反映されます。アプリごとに版を選ぶことはできません。
- **検索の設定は引き継がれます。** 検索対象のフィールド、AND / OR の初期値、語の数の上限はそのまま使われます。アプリの設定をやり直す必要はありません。
- **一覧画面の見た目は、更新しただけでは変わりません。** クイックフィルター・クイックボタン・集計・条件付き装飾は、アプリごとに設定するまで表示されません。
- **動作確認の状況:** 設定の引き継ぎは、2.0.3 を入れた環境で、アプリの設定を v1.0.1 と同じ形に置き換える方法（擬似検証）で確認しています。v1.0.1 が入った環境で 2.0.3 の ZIP を読み込む、実際の更新は、開発側では確認していません。心配な場合は、検証用の環境で先に試すことをおすすめします。

## 手順

### 1. ZIP を用意する

[Releases](https://github.com/youtotto/kintone-field-cross-search-plugin/releases/latest) から `field-cross-search-2.0.3-free-bundle.zip`（説明書付き）をダウンロードして解凍します。kintone に読み込むのは、中の `field-cross-search-2.0.3-free-plugin.zip` です（解凍しません）。

ファイルが壊れていないか確かめたいときは、`SHA256SUMS.txt` の SHA-256 と比べます。

### 2. （任意）今の設定を控える

元に戻す必要が出たときのために、アプリごとの設定を控えておけます。横断検索プラグインを設定しているアプリで、プラグインの設定画面を開き、ブラウザーの開発者ツールの Console で次を実行し、表示された内容をテキストファイルに保存します。

```js
JSON.stringify(kintone.plugin.app.getConfig('iaeigihohpbbjelmflbcbeimcjobagbg'))
```

### 3. プラグインを更新する

1. kintone システム管理 →「プラグイン」→「読み込む」で、`field-cross-search-2.0.3-free-plugin.zip` を ZIP のまま選びます。
2. プラグインの一覧で、名前が「一覧サポート for kintone」、バージョンが 2.0.3 になっていることを確認します。

### 4. 各アプリで確認する

1. 横断検索プラグインを使っていたアプリの一覧画面を開き、これまでと同じ語で検索して、同じように絞り込めることを確認します。標準の絞り込み（漏斗アイコン）を付けた一覧で検索した場合は、2.0.3 では標準の条件も残るため、件数が v1.0.1 のときより少なくなることがあります（v1.0.1 では、検索すると標準の絞り込みの条件が外れていました）。
2. プラグインの設定画面を開くと、「アプリ内横断検索プラグインの設定を引き継ぎました。」と表示されます。検索対象・AND / OR・語の数の上限が、これまでと同じことを確認します。確認だけなら保存する必要はありません。

### 5. 新しい機能を使うとき

1. アプリの「アプリの設定」→「プラグイン」で、一覧サポート for kintone の設定を開きます。
2. 使う機能（クイックフィルター・クイックボタン・集計・条件付き装飾）のスイッチをオンにして、内容を設定します。無料版で設定できる数は、クイックフィルター 5 つ、クイックボタン 5 個（1 個に条件 3 つまで）、集計 2 つ、条件付き装飾 3 ルールまでです。
3. 「保存」を押し、アプリの設定画面で「アプリを更新」を押します。

保存すると、新しい機能の設定が追加されます。横断検索の設定は、横断検索プラグインと同じ形のまま残ります。

## 元に戻すとき

- **プラグインを v1.0.1 に戻す:** kintone システム管理 →「プラグイン」→「読み込む」で、v1.0.1 の ZIP（Releases の v1.0.1 にある `field-cross-search-1.0.1-free-plugin.zip`）を読み込みます。これも環境全体に反映されます。2.0.3 は横断検索の設定を v1.0.1 と同じ形で残すので、v1.0.1 に戻しても検索の設定はそのまま使える作りですが、この動作は開発側では確認していません。新しい機能の設定は、v1.0.1 では使われません。
- **アプリの設定を控えに戻す（管理者向け）:** 手順 2 で控えた内容を使います。そのアプリのプラグインの設定画面の Console で、`kintone.plugin.app.setConfig(` と `)` の間に控えの内容（`{` から `}` まで）を貼り付けて実行し、「アプリを更新」を押します。`setConfig` はプラグインの設定画面でだけ動きます。

## よくある質問

**アプリごとに、横断検索プラグインのまま残せますか？**
できません。プラグインの版は環境全体で 1 つです。新しい機能を使わないアプリは、設定を変えなければ、これまでと同じ横断検索だけの画面のままです。

**更新した後、アプリの設定をやり直す必要はありますか？**
ありません。新しい機能を使うときだけ、設定して保存し、「アプリを更新」を押してください。

**標準の絞り込みと一緒に検索できますか？**
できます。2.0.3 では、標準の絞り込みや一覧自体の条件を残したまま、検索語で絞り込みます（v1.0.1 では、検索すると標準の絞り込みの条件が外れていました）。
