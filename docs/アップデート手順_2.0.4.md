# 一覧サポート for kintone 2.0.4 への更新

2.0.3からの更新で、アプリのプラグイン設定をやり直す必要はありません。同じプラグインIDのため、そのkintone環境で利用するすべてのアプリに更新が反映されます。

1. [最新版](https://github.com/youtotto/kintone-field-cross-search-plugin/releases/latest)から `field-cross-search-2.0.4-free-bundle.zip` をダウンロードし、展開します。
2. kintoneシステム管理 →「プラグイン」→「読み込む」で、中の `field-cross-search-2.0.4-free-plugin.zip` をZIPのまま選択します。bundle自体は読み込みません。
3. 名称「一覧サポート for kintone」、バージョン「2.0.4」を確認します。開いていた一覧画面は再読み込みしてください。
4. 設定済みの検索・集計を確認します。検証用のレコードを個別削除すると、集計欄の件数・合計・平均が更新されます。

直接読み込むplugin ZIP単体もReleaseにあります。整合性は `SHA256SUMS.txt` のSHA-256で確認できます。

横断検索プラグインv1.0.1から初めて更新する場合は、[2.0.3の移行説明](アップデート手順_2.0.3.md)の設定引継ぎ・追加機能の説明もご覧ください。読み込むZIPは最新版の2.0.4を使用します。v1.0.1から2.0.4への直接更新は今回実機未確認です。

過去の配布物はGitHub Releasesに保持しています。必要に応じて旧版へ戻す場合も、環境全体の利用アプリに反映されます。今回、旧版への切戻しの実機試験は行っていません。
